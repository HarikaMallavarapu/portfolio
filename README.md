# Harika Mallavarapu — AI & Data Solutions Engineer Portfolio

A warm, friendly, animated portfolio built with React, GSAP, and Vite, featuring interactive animations, responsive layout, and personal projects.

Portfolio for **[Harika Mallavarapu](https://github.com/harikamallavarapu04)**.

## ✨ Highlights

- **Hero:** Interactive cut-out portrait with smooth cursor tracking.
- **About:** Photo stack shuffle with multiple professional roles.
- **Work:** Project cards with interactive physics scatter and tidy scroll animations.
- **Journey:** Scrapbook road map with polaroid photos and self-drawing path.
- **Toolbox:** Interactive draggable sticker sheet of skills with shuffle.
- **Milestones:** Certificate wall and rolling odometer metrics.
- **Contact:** Clean contact card with die-cut sticker and quick mail action.

## 🛠 Tech Stack

React 19 · Vite · GSAP (ScrollTrigger, Draggable) · Lenis · Bricolage Grotesque, DM Sans and Caveat fonts

## 🚀 Getting Started

```bash
npm install
npm run dev        # http://localhost:5173
```

Build for production:

```bash
npm run build      # outputs to dist/
npm run preview    # preview the build locally
```
